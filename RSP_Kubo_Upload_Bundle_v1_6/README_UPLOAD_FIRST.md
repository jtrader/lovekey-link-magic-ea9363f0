This bundle collates the RSP Genesis NFT, protocol documents, key clause, tiers, service price matrix, future credit layer, developer library architecture, signal model, and vertical integration strategy for Kubo/IPFS upload.

**Translate behaviour. Synchronise the signal. Burn the identifiable source.**

## Kubo upload process

1. Upload every file listed in `rsp_kubo_upload_manifest_v1_6.json`.
2. Replace the matching placeholders in `rsp_genesis_metadata_upload_ready_v1_6.json`.
3. Save the result as `rsp_genesis_metadata_final_v1_6.json`.
4. Upload the final metadata JSON to Kubo/IPFS.
5. Use the final metadata URI for minting: `ipfs://FINAL_METADATA_CID`.
